PART 1  -  items 1-5: the framework class and the basic notions
==============================================================================
Framework: AF(args=['a', 'b', 'c', 'd'], attacks=[a->b, b->c, c->d])
  conflict-free {}        : True
  conflict-free {a, c}    : True
  conflict-free {a, b}    : False
  'c' defended by {a}   : True
  'c' defended by {}    : False
  'd' defended by {a}   : False
  'd' defended by {b}   : True
  F({}      ) = {a}
  F({a}     ) = {a, c}
  F({a, c}  ) = {a, c}
  {c}      admissible: False  complete: False
  {a}      admissible: True   complete: False
  {a, c}   admissible: True   complete: True

PART 2  -  the mechanism, best responses, strategyproofness
==============================================================================
Agent 0 owns {al, be}; agent 1 owns {de}; attacks: al<->de, al->be
  reports ['{al, be}', '{de}']         -> grounded {}
  reports ['{be}', '{de}']             -> grounded {be, de}
  reports ['{al}', '{de}']             -> grounded {}
  reports ['{al, be}', '{}']           -> grounded {al}

Best responses of agent 0 against agent 1 revealing {de}: utility 1, reports ['{be}']
Strategyproof (truth dominant for every agent)? False
   agent 0 vs { 1: {de} }: truthful utility 0, can reach 1 by revealing ['{be}']
Theorem 5.4 condition holds? False; violating (agent, alpha, beta): [(0, 'al', 'be')]

A strategyproof instance whose condition fails (hiding alpha just trades alpha for beta):
  single agent with al->be:  strategyproof = True   Theorem 5.4 condition = False

A strategyproof instance whose condition holds (even path al->x->be through another agent):
  strategyproof = True   condition = True
