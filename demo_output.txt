==============================================================================
STEP 1  [Item 1]  The argumentation framework class
==============================================================================
Figure 5.1: alpha1 has two defeaters (2 and 4), which are defeated by 3 and 5 respectively.
>>> af = ArgumentationFramework({1,2,3,4,5}, {(3,2),(2,1),(5,4),(4,1)})
      = AF(args=[1, 2, 3, 4, 5], attacks=[2->1, 3->2, 4->1, 5->4])
>>> af.attackers_of(1)
      = {2, 4}
>>> af.targets_of(3)
      = {2}
>>> af.attacked_by({3, 5})        # S+ = everything attacked by the set
      = {2, 4}
>>> ArgumentationFramework.parse('a->b, b->c')      # compact constructor
      = AF(args=['a', 'b', 'c'], attacks=[a->b, b->c])

==============================================================================
STEP 2  [Item 2]  Conflict-free test
==============================================================================
A set is conflict-free if no member attacks a member.
>>> is_conflict_free(af, set())
      = True
>>> is_conflict_free(af, {1, 3, 5})
      = True
>>> is_conflict_free(af, {3, 2})
      = False
>>> is_conflict_free(af, {2, 4})
      = True
    -> {3, 2} fails because 3 attacks 2; {2, 4} is fine (2 and 4 do not attack each other).

==============================================================================
STEP 3  [Item 3]  Can an argument be defended by S?
==============================================================================
S defends a when every attacker of a is itself attacked by a member of S.
>>> is_defended(af, 1, {3, 5})
      = True
>>> is_defended(af, 1, {3})
      = False
>>> is_defended(af, 1, set())
      = False
>>> is_defended(af, 3, set())
      = True
    -> 1 needs both 3 (kills 2) and 5 (kills 4); the unattacked arguments 3 and 5 are defended by the empty set.

==============================================================================
STEP 4  [Item 4]  Characteristic function F(S) = arguments defended by S
==============================================================================
>>> characteristic_function(af, set())
      = {3, 5}
>>> characteristic_function(af, {3, 5})
      = {1, 3, 5}
>>> characteristic_function(af, {1, 3, 5})
      = {1, 3, 5}
    -> F(empty) = {3,5}, F({3,5}) = {1,3,5}, F({1,3,5}) = {1,3,5}: matches the book (p.184).

==============================================================================
STEP 5  [Item 5]  Admissible set and complete extension
==============================================================================
Admissible = conflict-free and defends all its members; complete = admissible and contains everything it defends.
>>> is_admissible(af, set()), is_complete(af, set())
      = True, False
>>> is_admissible(af, {3, 5}), is_complete(af, {3, 5})
      = True, False
>>> is_admissible(af, {1, 3, 5}), is_complete(af, {1, 3, 5})
      = True, True
>>> is_admissible(af, {1}), is_complete(af, {1})
      = False, False
>>> is_admissible(af, {2, 3}), is_complete(af, {2, 3})
      = False, False
    -> {3,5} is admissible but not complete (it defends 1 but does not contain it) - Example 5.6.
>>> admissible_sets(af)
      = [{}, {3}, {5}, {3, 5}, {1, 3, 5}]
    -> exactly the admissible sets listed in Example 5.5.

==============================================================================
STEP 6  [Item 6A]  Grounded extension (least fixed point of F)
==============================================================================
>>> grounded_extension(af)           # Figure 5.1
      = {1, 3, 5}
    iteration trace  F^k(empty):
      F^1(empty) = {3, 5}
      F^2(empty) = {1, 3, 5}
      F^3(empty) = {1, 3, 5}
>>> grounded_extension(af)           # Figure 5.3 (b->a, c->b, d->b, c<->d, e->d)

#  PART 2 - STRATEGIC ARGUMENTATION (grounded direct argumentation mechanism)
##############################################################################

==============================================================================
STEP 12  [Setup]  Book Example 5.10
==============================================================================
Three agents:  x owns {1,4,5},  y owns {2},  z owns {3}.   Defeats R = {(1,2), (2,3), (3,4), (3,5)}.
Utility of an agent = number of ITS OWN arguments that end up accepted (acceptability maximiser).
    StrategicGame(attacks=frozenset({(2, 3), (1, 2), (3, 4), (3, 5)}), agent_arguments=(frozenset({1, 4, 5}), frozenset({2}), frozenset({3})))

==============================================================================
STEP 13  [Item 1]  The mechanism: grounded extension of the graph induced by the revealed arguments
==============================================================================
>>> grounded_direct_mechanism(R, [{1,4,5}, {2}, {3}])   # everybody truthful
      = {1, 3}
      u_x = 1
      u_y = 0
      u_z = 1
    -> outcome {1,3}: 1 wins, kills 2, so 3 is defended and kills 4 and 5.  u_x=1, u_y=0, u_z=1.
    -> (book misprint: it prints u_y(o,{3})=1 and u_z(o,{2})=0 - the two argument sets are swapped.)
>>> grounded_direct_mechanism(R, [{4,5}, {2}, {3}])   # x hides argument 1
      = {2, 4, 5}
      u_x = 2
    -> hiding 1 breaks the defeat chain 1->2->3->4,5: outcome {2,4,5}, so x now has 2 accepted arguments instead of 1.

==============================================================================
STEP 14  [Item 2]  Best responses: enumerate every subset x could reveal, others fixed
==============================================================================
    other agents truthful: y reveals {2}, z reveals {3}.  All 2^3 = 8 reports of x and their utilities:
      x reveals {}         -> outcome {2}          u_x = 0
      x reveals {1}        -> outcome {1, 3}       u_x = 1
      x reveals {4}        -> outcome {2, 4}       u_x = 1
      x reveals {5}        -> outcome {2, 5}       u_x = 1
      x reveals {1, 4}     -> outcome {1, 3}       u_x = 1
      x reveals {1, 5}     -> outcome {1, 3}       u_x = 1
      x reveals {4, 5}     -> outcome {2, 4, 5}    u_x = 2
      x reveals {1, 4, 5}  -> outcome {1, 3}       u_x = 1
>>> best_responses(game, x, {y: {2}, z: {3}})
      = utility 2, reports [{4, 5}]
    -> x's unique best response is {4,5}: lying by omission pays.  Truthful {1,4,5} gives only 1.
    agent y against truthful others: best utility 0, best reports [{}, {2}]
    agent z against truthful others: best utility 1, best reports [{3}]
    -> for y and z the truthful report is among the best responses (book: it weakly dominates revealing nothing).

==============================================================================
STEP 15  [Item 3]  Theorem 5.3: is truth-telling the best response against EVERY combination of the others' subsets?
==============================================================================
>>> is_strategyproof(Example 5.10)
      = False   (1 counterexamples)
    first counterexample: agent x, others reveal {'y': '{2}', 'z': '{3}'}, truthful utility 1, best achievable 2 by revealing [{4, 5}]
    agents with a profitable deviation: ['x']

    Book Example 5.11: add argument 6 (owned by x) and the defeat (6, 3):  x = {1,4,5,6}
>>> is_strategyproof(Example 5.11)
      = True      (truthful outcome {1, 4, 5, 6}: x gets all 4 of its arguments accepted)

==============================================================================
STEP 16  [Item 4]  Theorem 5.4: does some agent hold alpha, beta with an odd-length directed path alpha ~> beta?
==============================================================================
If NO agent does, the mechanism is guaranteed strategyproof (sufficient condition).
>>> satisfies_theorem_5_4(Example 5.10)
      = holds: False, violations (agent, alpha, beta): [('x', 1, 4), ('x', 1, 5)]
    -> x owns 1 and 4; odd path 1 -> 2 -> 3 -> 4 (length 3).
    -> x owns 1 and 5; odd path 1 -> 2 -> 3 -> 5 (length 3).
    -> so the condition cannot certify Example 5.10, and indeed it is manipulable.
>>> satisfies_theorem_5_4(Example 5.11)
      = holds: False, violations [('x', 1, 4), ('x', 1, 5)]
    -> condition FAILS but the mechanism IS strategyproof (step above): the condition is sufficient, not necessary.
    -> why: argument 6 defeats 3 whenever x reveals it, so 4 and 5 never depend on 1 - 6 'cancels' the indirect defeat.

    Handling cycles - parity search, so the check always terminates:
      graph                                       odd simple path   odd walk (may repeat nodes)
      a->x, x->x (loop), x->b                     False             True
      2-cycle a<->b, odd closed path a~>a         False             False
      3-cycle a->b->c->a, odd closed path a~>a    True              True
    -> the loop example has an odd walk (a,x,x,b: length 3) but no odd simple path - the two readings are both implemented.

==============================================================================
STEP 17  [Misprints]  The two misprints of the book, verified by the code
==============================================================================
    (1) Example 5.10 utilities: y owns {2} -> u_y = 0; z owns {3} -> u_z = 1 (the book swaps the argument sets).
    (2) Which argument cancels the indirect self-defeat in Example 5.11?
        remove 6: strategyproof? False   (x can gain again)
        remove 5: strategyproof? True    (still dominant)
    -> so it is argument 6, not 5 (5 defeats nothing and cannot influence anyone).

==============================================================================
STEP 21  [Q3]  Instances that ARE strategyproof although the Theorem 5.4 condition FAILS
==============================================================================
    strategyproof instances: 1258;  of those the condition fails in 1116 (88.7% of the strategyproof ones; 1116 instances to note)
    why they are strategyproof (violating pairs classified by comparing 'reveal all' vs 'hide alpha'):
      rescue_offset        523 pairs   hiding alpha DOES free beta, but the agent loses alpha (or another argument) at the same time: a swap, no net gain
      beta_hopeless       3949 pairs   beta can never be accepted whatever anyone reveals (it attacks itself, or an argument nobody can defeat attacks it), so nothing is to be gained
      alpha_irrelevant     356 pairs   beta's status is the same with or without alpha (chain cut by others, or alpha is dead anyway)
      hiding_hurts_beta     92 pairs   hiding alpha never frees beta and sometimes loses it: alpha's real effect on beta is supportive

    One small instance of each class, worked through:

    [rescue_offset]
      attacks: [(2, 1)]
      agents : agent 0 owns {3, 4}; agent 1 owns {0, 5, 6}; agent 2 owns {1, 2}
      violating pair: agent 2 owns 2 and 1 (odd path 2 ~> 1)
      everyone truthful      -> outcome {0, 2, 3, 4, 5, 6}, agent 2 utility 1
      agent 2 hides 2        -> outcome {0, 1, 3, 4, 5, 6}, agent 2 utility 1
    -> hiding alpha DOES free beta, but the agent loses alpha (or another argument) at the same time: a swap, no net gain

    [beta_hopeless]
      attacks: [(0, 1), (3, 1), (4, 1)]
      agents : agent 0 owns {0, 2, 5}; agent 1 owns {}; agent 2 owns {1, 3, 4}
      violating pair: agent 2 owns 3 and 1 (odd path 3 ~> 1)
      everyone truthful      -> outcome {0, 2, 3, 4, 5}, agent 2 utility 2
      agent 2 hides 3        -> outcome {0, 2, 4, 5}, agent 2 utility 1
    -> beta can never be accepted whatever anyone reveals (it attacks itself, or an argument nobody can defeat attacks it), so nothing is to be gained

    [alpha_irrelevant]
      attacks: [(2, 1), (4, 2)]
      agents : agent 0 owns {}; agent 1 owns {1, 2, 3, 4, 5}; agent 2 owns {0}
      violating pair: agent 1 owns 2 and 1 (odd path 2 ~> 1)
      everyone truthful      -> outcome {0, 1, 3, 4, 5}, agent 1 utility 4
      agent 1 hides 2        -> outcome {0, 1, 3, 4, 5}, agent 1 utility 4
    -> beta's status is the same with or without alpha (chain cut by others, or alpha is dead anyway)

    [hiding_hurts_beta]
      attacks: [(2, 4), (2, 5), (3, 2), (3, 4), (4, 0)]
      agents : agent 0 owns {0, 1, 3, 4, 5}; agent 1 owns {2}; agent 2 owns {}

    -> hiding alpha never frees beta and sometimes loses it: alpha's real effect on beta is supportive
